# xpnq.github.io

Personal website, served at **https://xpnq.github.io**.

Plain static HTML/CSS — no build step. GitHub Pages serves it directly from the
default branch.

## Edit it

- `index.html` — About page: hero bio, selected projects, news.
- `research.html` — Publications and research interests.
- `athletics.html` — Non-work interests.
- `assets/style.css` — all styling (light + dark mode via `prefers-color-scheme`).
- `assets/img/` — replace `profile.svg` and `project*.svg` with your own images
  (update the `src="..."` paths in the HTML if you change file names/extensions).

Search the HTML for `Your Name`, `#` placeholder links, and `(placeholder)`
text, and replace with your own content. Add a `assets/cv.pdf` for the CV link.

Changes pushed to the default branch go live within a minute or two.
